5. STS, AGV, RMG 개선
5-1 STS, RMG : 하역/적재 시, 흔들림으로 인한 속도 저하 개선
5-2 AGV : 이동 시, 병목 현상 개선, 바퀴 구현

6. 실시간 바람 물리 연동 (완료)
6-1 컨테이너 : 실시간 풍속·풍향과 컨테이너 이동 속도를 이용한 상대풍 항력 적용
6-2 STS : 풍속 센서 값을 현수 동역학에 연결하여 스프레더·컨테이너 흔들림 반영
6-3 Anti-Sway : 풍압 평형 위치 선행 보상과 로프 각도·각속도 피드백으로 변화하는 바람 보상
6-4 관제 : STS별 풍속, 풍압 보상량, 흔들림 각도·각속도를 대시보드 데이터에 추가
6-5 돌풍 : 평균풍과 독립된 6~12초 돌풍(2~5m/s 증속, 최대풍 구간 포함, 이후 5~15분 간격)을 컨테이너 항력·STS 센서·Anti-Sway에 연동

돌풍 범위와 발생 간격은 부산항 DGT 실측값이나 장비 운전정지 기준이 아니라 정상 운전 비교를 위한 시뮬레이션 가정이다. 평균풍 대표값 3.5m/s는 [기상청 부산 지역별 기후특성](https://www.weather.go.kr/w/climate/statistics/region.do?area=7)의 계절 평균풍속 약 3.2~3.7m/s 범위를 참고한다.

7 환경 - 파랑·너울에 따른 선박 운동
7-1 Sea State : 항내 단주기 파랑(0.10~0.40m, 4.5~7초)과 장주기 너울(0.15~0.60m, 8~13초)을 독립 성분으로 합성
7-2 선박 응답 : 3척에 서로 다른 위상을 적용하고, 축소 응답계수로 surge/sway/heave 및 roll/pitch를 계산
7-3 적재 연동 : 선박과 선상 컨테이너의 위치·회전·속도, STS 픽업 목표와 센서 입력을 동일한 선박 운동으로 갱신
7-4 제어 : `Ctrl+1`로 Sea Motion을 OFF/ON하며, OFF 동안 파랑 시계를 동결하고 선박을 기준 자세로 복귀

파고 구간은 기상청 해양기후정보의 `낮음(1m 미만)` 범위 안에서 정상 항만 작업을 비교하기 위한 가정이다. 실제 부산항 운항 모델로 사용하려면 대상 선박의 RAO, 적재상태, 계류삭·방충재 강성 및 부두별 관측 스펙트럼으로 응답계수를 교체해야 한다.
