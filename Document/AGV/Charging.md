# AGV 배터리와 충전소

통합 터미널의 작업자 대기소 옆 직원 주차장(공컨테이너 장치장과 안벽 사이)을 AGV 고속 충전소 6면으로 변경했다. 남쪽으로 진입하고 북쪽으로 출차하며 기존 FMS 도로 예약, LiDAR 및 차량 충돌 방지 제어를 사용한다. 기존 60개 AGV 대기 위치는 유지한다.

- 초기화 시 모든 AGV는 80%로 시작한다.
- 사용자가 지정한 근사 성능을 선형 모델로 적용한다. 시뮬레이션 가동 시간 8시간 동안 80%에서 20%까지 소모하며, 20%에서 80%까지 충전에 30분이 걸린다. 실제 장비의 전력·열·충전 곡선 모델은 아니다.
- 배속이 반영된 시뮬레이션 시간을 사용한다. 작업 및 이동·교통 대기는 소모 시간에 포함하고, 유휴 대기와 시뮬레이션 일시정지는 제외한다.
- 잔량 20% 이하에서는 신규 작업 및 STS 직접 재배정을 금지한다. 진행 중인 운반은 화물을 안전하게 인계한 뒤 기존 대기 위치를 거쳐 충전소로 이동한다.
- 충전 구역은 차량 한 대씩 예약한다. 구역이 없으면 기존 대기 위치에서 기다린다. 다른 충전된 가용 차량은 기존 ETA·작업량 배차 규칙으로 작업을 이어받는다.
- 예약한 구역에 빈 차량이 완전히 정차한 경우만 충전한다. 충전 필요 상태는 80%까지 유지하므로 20%를 조금 넘었다고 중도 배차하지 않는다.
- 80%에서 충전을 끊고 기존 대기 위치로 돌아와 배차 대상에 복귀한다. 복귀 이동 중에도 배터리를 소모한다. 충전소 이동으로 20% 아래에 도착하면 충전에 30분보다 조금 더 걸린다.
- 차량 이름표에 배터리 백분율 및 CHARGING 상태를 표시한다. 대시보드 AGV 상세에는 잔량, 충전 상태, 충전 구역을 표시한다.

배터리 값은 `battery_percent`, `charging`, `needs_charge`, `dispatch_eligible`, `charge_limit_percent`, `charging_bay`로 대시보드에 전달한다. 충전 관련 단계는 10(충전소 이동), 11(대기 위치 복귀), 12(충전)이다.
