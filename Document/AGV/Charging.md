# AGV 배터리와 충전소

통합 터미널의 작업자 대기소 옆 직원 주차장(공컨테이너 장치장과 안벽 사이)을 북쪽으로 확장한 AGV 대기·충전소 60면으로 변경했다. 8열 × 8행 중 60면을 사용하며(마지막 행 4대), 열 간격은 도면 좌표 9m로 교통 예약 안전 여유까지 확보한다. 각 AGV에 독립 대기·충전 위치를 배정한다. 인접 행이 한 방향 진입/출구 통로를 공유하며 기존 FMS 도로 예약, LiDAR 및 차량 충돌 방지 제어를 사용한다. 초기 배치와 리셋 시 모든 AGV는 이 대기소에 위치한다.

- 초기화 시 모든 AGV는 80%로 시작한다.
- 사용자가 지정한 근사 성능을 선형 모델로 적용한다. 시뮬레이션 가동 시간 8시간 동안 80%에서 20%까지 소모하며, 20%에서 80%까지 충전에 30분이 걸린다. 실제 장비의 전력·열·충전 곡선 모델은 아니다.
- 배속이 반영된 시뮬레이션 시간을 사용한다. 작업 및 이동·교통 대기는 소모 시간에 포함하고, 유휴 대기와 시뮬레이션 일시정지는 제외한다.
- 잔량 20% 이하에서는 신규 작업 및 STS 직접 재배정을 금지한다. 진행 중인 운반은 화물을 안전하게 인계한 뒤 대기소의 지정 위치로 돌아와 충전한다.
- 충전 구역은 AGV별 전용 위치를 사용한다. 다른 충전된 가용 차량은 기존 ETA·작업량 배차 규칙으로 작업을 이어받는다.
- 예약한 구역에 빈 차량이 완전히 정차한 경우만 충전한다. 충전 필요 상태는 80%까지 유지하므로 20%를 조금 넘었다고 중도 배차하지 않는다.
- 80%에서 충전을 끊고 같은 자리에서 배차 대상에 복귀한다. 충전소 이동으로 20% 아래에 도착하면 충전에 30분보다 조금 더 걸린다.
- 차량 이름표에 배터리 백분율 및 CHARGING 상태를 표시한다. 대시보드 AGV 상세에는 잔량, 충전 상태, 충전 구역을 표시한다.

배터리 값은 `battery_percent`, `charging`, `needs_charge`, `dispatch_eligible`, `charge_limit_percent`, `charging_bay`로 대시보드에 전달한다. 충전 관련 단계는 11(충전소 이동), 12(대기 위치 복귀), 13(충전)이다. 기존 10단계는 두 번째 20ft 컨테이너의 개별 STS 적재에 사용하므로 충전 상태와 분리한다.

Tab 카메라는 대기소 → 현재 설정된 선박별 안벽 → 기존 크레인 순서로 순환한다. Home은 전체, End는 근접 시점이다.
