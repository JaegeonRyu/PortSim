# 선박 자료 불러오기와 배치 적용

HUD에서 선박별 직접 설정 또는 불러오기 모드를 선택합니다. 직접 설정에서는 슬라이더로 수량을 정하고, 불러오기에서는 슬라이더 대신 양하/선적 목록 및 선내 적재도 CSV 선택 버튼을 표시합니다. 변경값은 대기 설정이며, 리셋 버튼을 눌렀을 때 실제 컨테이너 수·ID·위치에 적용하고 전체 시뮬레이션 진행 상태를 초기화합니다. 파일을 고르거나 모드를 바꾸는 것만으로 현재 배치는 바뀌지 않습니다.

- 한 CSV 행이 한 컨테이너입니다. 마지막으로 불러온 파일이 해당 선박의 전체 배치를 교체합니다. 두 파일을 합산하지 않습니다.
- 양하/선적 목록도 DISCHARGE/LOAD 구분과 관계없이 모든 행을 배치 대상으로 사용합니다. 작업 종류에 따른 양하·선적 작업 순서 자동 생성 기능은 아닙니다.
- Operations/example_operations.csv: 5개 배치(양하 표기 3건, 선적 표기 2건).
- Stowage/example_stowage.csv: 4개 배치.
- 직접 설정으로 돌아오면 이전 직접 설정 수량을 복원하고 다시 슬라이더로 조절할 수 있습니다. 선택한 모드와 직접 설정 수량은 저장됩니다. 불러오기 모드에서 파일을 선택하지 않았다면 리셋 시 안내를 표시하고 현재 배치를 유지합니다.
- 헤더만 있는 CSV를 선택하고 리셋하면 해당 선박의 컨테이너를 0개로 변경합니다.

## CSV 형식

UTF-8, 쉼표 구분, 따옴표 없는 단순 CSV입니다. 헤더와 열 순서는 예시와 동일해야 합니다.

- 작업 목록: container_id,operation,bay,row,tier
- 선내 적재도: container_id,bay,row,tier
- operation: DISCHARGE 또는 LOAD.
- 최대 2MB. 현재 선박 모델은 10 Bay × 10 Row × 2 Tier이므로 최대 200개를 실제 배치할 수 있습니다.
- 시뮬레이터 슬롯: Bay 1~10, Row 1~10, Tier 1~2.
- 예시의 갑판 표기: 홀수 Bay 1,3,...,19를 시뮬레이터 Bay 1~10에 대응시키고 Tier 82/84를 Tier 1/2에 대응시킵니다. Row는 1~10입니다. 두 표기를 한 파일에 혼용할 수 없습니다.
- Bay 간격 18m, Row 간격 3m, Tier 간격 2.59m로 기존 선박 모델의 슬롯 위치를 사용합니다. 빈 Bay/Row 간격은 유지됩니다.
- 위치 중복, 범위 초과, 중복 ID, 상단 컨테이너 아래 지지 화물 누락은 거부하고 기존 배치를 유지합니다.

## 저장과 복원

자료 루트는 Unreal 프로젝트 폴더의 상위에 있는 F:/Git Repository/PortSim/VesselData입니다.

선박 수, 직접 설정 수량, 선택 모드, 선택한 파일 종류와 CSV 내용은 PortSim/Saved/SimulationSettings.json에 함께 저장합니다. 실행하면 마지막으로 저장한 설정과 파일 배치로 시작합니다. 원본 CSV를 이동하거나 삭제해도 저장된 배치를 복원할 수 있습니다. 별도의 Imported 폴더는 만들지 않습니다.

실행 중 직접 설정/불러오기 모드나 수량·파일을 변경하면 다음 적용할 설정으로 저장합니다. 현재 배치는 유지되며 리셋을 눌렀을 때 변경된 설정을 적용합니다. 파일 수정 내용을 반영하려면 다시 불러온 뒤 리셋하세요.

예시의 SIMU 번호는 설명용 가상 ID이며, EDI 파일은 지원하지 않습니다.
